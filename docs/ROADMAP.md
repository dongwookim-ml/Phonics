# 소리 마을 개선 계획 (2026-10-25)

5세 아이가 영어 파닉스를 배우는 게임이라는 점을 기준으로 프로젝트 전체를 다시 점검하고,
중요도에 따라 고칠 것과 더할 것을 정리했습니다.

## 어떻게 점검했나

- 일곱 영역을 독립된 점검자(에이전트)가 나눠 맡았습니다: 학습 내용·난이도, 공주 마을 건물,
  캡틴 마을 건물과 로봇 부품, 화면 디자인, 음성·오디오, 5세 아이 기준 게임 디자인, 코드·보안.
- 모두 실제 게임을 Chromium(Playwright)으로 직접 플레이하며 확인했습니다. 화면 약 600장을 찍었고,
  문제를 약 2만 번 만들어 보았고, 녹음 클립 1만 2천 개를 측정했습니다. 건물을 하나씩 눌러 보고
  계정 동기화도 재현했습니다.
- 녹음 클립은 GitHub Actions에서 음성 인식기(Whisper)로 들어 보고, 음향 분석으로도 따로 확인했습니다.
- Codex 플러그인은 이 환경에 OpenAI 인증이 없어 실행하지 못했습니다(Codex CLI는 설치했지만 로그인 불가).
  대신 서로 독립된 점검자들이 교차 검토했고, 계획도 두 명의 별도 검토자(유아 문해·게임 디자인 관점,
  엔지니어링·배포 위험 관점)에게 비판적으로 보게 해서 반영했습니다(아래 "계획 검토" 참고).

## 부모님이 알려주신 문제: 원인과 해결

| 알려주신 문제 | 확인한 원인 | 해결 |
|---|---|---|
| 단어 앞에 관사가 들림 | 퀴즈 글에는 관사가 없습니다. 원인은 녹음입니다. 농부·A집·상인과 캡틴 캐릭터 4명이 쓰는 Joey(neural) 음성이 b/d/g/j로 시작하는 단어 79%에서 110–200ms 동안 "어-" 소리를 냅니다("uh-bear"). 생성형 음성 일부는 단어를 두 번 말했습니다("dot dot", "dragon dragon", "banana banana"). | 모든 음성을 Amazon Polly **Generative** 엔진으로 옮기고, 단어는 "Cat."처럼 완결된 문장으로 녹음합니다. 단어 앞 웅얼거림을 잘라내고, 녹음할 때마다 자동 검사(음향 분석과 음성 인식)를 통과해야 쓰도록 했습니다. |
| 난이도 설계(쉬운 것부터, 못 풀면 다시 쉽게) | 지금은 아직 맞히지 않은 문제를 무작위로 냅니다. 모음 문제의 71%에 한국어 화자가 아직 구분하기 어려운 모음 쌍이 섞이고, 철자 문제는 늘 6–7개 타일로 시작합니다. | 문제 종류마다 3–6단계를 둡니다. 처음 맞힌 기록 기준으로 최근 6번 중 5번이면 한 단계 올리고, 2번 연속 틀리면 내립니다. 틀린 직후에는 쉬운 문제를 하나 내고, 4문제마다 한 단계 아래를 복습합니다(아이 400명을 가정한 시뮬레이션으로 정답률 약 80%가 되게 맞췄습니다). |
| 틀렸을 때 피드백 | 틀리면 "다른 친구를 도와주고 다시 와"라는 영어 문장만 나오고 대화창이 닫힙니다. 정답은 끝내 알려주지 않고, 글자 집에서는 다시 말을 걸어도 대답하지 않아 막힙니다. | 첫 번째로 틀리면 고른 카드의 그림과 단어를 들려주고 힌트를 준 뒤 바로 다시 고르게 합니다. 두 번째로 틀리면 정답을 빛나게 보여주고 소리 내어 들려준 다음, 아이가 그 카드를 눌러 끝내게 합니다. 문제는 나중에 다시 나옵니다. 철자 문제는 글자를 놓을 때마다 바로 확인합니다. |
| 문제를 더 다양하게(철자 3→4→5글자) | 철자 문제 단어가 68개뿐이고 3글자와 4글자가 섞여 있습니다. 그림이 헷갈리는 단어도 28개 있습니다(sit=의자, top=TOP 표지판). | 새 단어 은행을 넣습니다: 3글자 CVC 42개, 4글자 자음군 22개, 5글자 이상 14개, sh·ck 같은 이중글자 27개, 라임 41세트, 쉬운 문장 20개와 어려운 문장 28개, 글자 E·O·K·V·W·Z. 철자는 첫 글자를 주는 3글자부터 시작해 4글자, 5글자로 올라갑니다. |
| 5세에 맞는 게임 요소 | 선물이 마을에서는 정답 16개, 전체로는 약 37개 뒤에 바닥나고, 그 뒤로는 이미 가진 것을 "선물"이라고 줍니다. 요정 가루와 배터리는 쓸 곳이 없고, 별은 30개가 넘으면 의미가 없습니다. | 단어 스티커 앨범, 선물 게이지, 다음 문까지 남은 별 표시와 문이 열릴 때의 축하, 집·마을 메달, 가루와 배터리로 자라는 요정/도우미 친구, 연속 정답 응원, 매일 보물상자, 미니게임(낚시, 자석 크레인)을 넣습니다. |
| 들어갈 수 없는 집 | 버섯집 4채·유니콘 집 5채·요정 집 6채와 캡틴 마을 건물 19채가 문은 그려져 있지만 문 연결이 없습니다. 문 아치는 바닥 두 칸만 반응하고, 요정 마을 문 아치를 누르면 T 집으로 들어갑니다. | 집마다 테마 실내와 주민을 넣습니다. 문 아치·기둥·자물쇠·동굴 입구 어디를 눌러도 해당 길로 가고, 소품을 누르면 영어 단어를 들려줍니다. |
| 캡틴 로봇 팔·다리가 잘 구분되지 않음 | 정비대·선물 미리보기에서 로봇이 자동차에 앉아 있어 다리가 아예 보이지 않습니다(다리 종류끼리 0픽셀 차이). 팔은 4×3픽셀 손만 다르고, 종류끼리 23–30픽셀밖에 차이 나지 않습니다. | 차 선물이 아니면 미리보기를 서 있는 모습으로 보여줍니다. 팔과 다리를 크게 다시 그려 부품마다 고유한 색과 모양을 줍니다(차이 85–176픽셀). 부품을 달면 그 부품만 확대해 보여주고 집게·드릴 등이 움직이는 연출을 넣습니다. |

## 중요도별 문제 목록

P0 = 잘못 가르치거나 진행이 막힘, P1 = 아이의 학습·경험에 큰 문제, P2 = 분명한 개선, P3 = 있으면 좋음.

### P0
- 글자 소리에 모음이 붙어 녹음됨("S says sss"가 "suh"로 들림). 파닉스의 기본을 잘못 가르칩니다.
  → 각 목소리가 녹음한 단어에서 순수한 /m/ /s/ 소리를 잘라 씁니다.

### P1
- 오답 피드백 없음, 글자 집에서 막힘, 캡틴 악당과 끝없이 반복, 철자는 다 채워야만 확인 (게임 디자인·학습)
- 난이도 설계 없음, 그림 없이 글자만 있는 첫 문제, 한국어 화자가 구분하기 어려운 모음 쌍이 무작위로 나옴 (학습)
- 헷갈리는 그림 28개, 구형 iPad에서 빈칸으로 보이는 이모지 12개 (학습)
- 들어갈 수 없는 집·건물 34채, 문 아치와 동굴 입구가 거의 반응하지 않음 (공주·캡틴 마을)
- 로봇 부품 미리보기에서 다리가 사라짐, 팔·다리 종류 구분이 어려움 (캡틴)
- 손님 모드로 하던 기기에서 로그인하면 기록이 사라짐(별 42개가 0개가 되는 것을 재현함) (코드)
- 한 계정을 태블릿 두 대에서 동시에 쓰면 서로를 시작 화면으로 되돌림 (코드)
- Joey 음성의 "어-" 소리, neural 음성의 불분명한 단어 발음, 깨진 클립 5개 (음성)
- 긴 단어(helicopter, strawberry)가 답 카드 밖으로 넘침 (화면)
- 선물이 금방 바닥남 (게임 디자인)

### P2 (일부)
- 느린 네트워크에서 업로드가 겹쳐 게임 도중 새로고침됨. 부모 패널이 게임을 실제로 멈추지 않음.
  오프라인일 때 맞는 비밀번호를 틀렸다고 표시함.
- 정답 직후 ✖를 누르면 주는 사람 없는 선물 카드가 뜸(타이머 경쟁).
- 음성 서버(/tts)를 누구나 제한 없이 쓸 수 있음. 캐시가 수백 MB까지 커질 수 있음.
- 목소리마다 음량 차이가 6.5 LU. 효과음이 단어를 가림.
- 마을 사람 일부가 건물 뒤에 완전히 가려짐. 화면 위아래 흐림 효과가 글자 간판을 흐리게 함.
  파닉스 강조색 대비가 2.3:1로 낮음. 버튼이 64px보다 작음.
- 별이 30개를 넘으면 쓸모가 없음. 문이 열려도 축하가 없음. 정답 앞에 인사말이 4–6초 이어짐.
- 부모 패널에 설정이 없음(시간 제한, 그림 힌트 기본값 등).

### P3 (일부)
- 휴대폰 가로 화면 지원, 캡틴판에 남은 공주판 문구, 효과음 재사용, 부모 패널 값 이스케이프, 로그인 잠금 악용 가능성.

## 계획 검토에서 바뀐 것

두 검토자 모두 "수정 필요"라고 판단했고, 다음을 반영했습니다.

- **보상**: 남은 카드가 하나뿐인 상태로 다시 고르게 하지 않습니다(그때는 바로 정답을 보여줍니다).
  다시 시도해서 맞히면 별만 주고 선물은 주지 않습니다. 정답을 보여준 뒤 눌러서 끝내면 칭찬만 합니다.
  이미 가진 물건을 "선물"로 주지 않습니다.
- **소리 먼저**: 정답을 알려줄 때 소리로 끊어 읽은 뒤 단어를 말합니다("/p/ /e/ /n/ … pen!").
  c와 k 타일은 한 문제에 함께 나오지 않고, 쉬운 단계에서는 멀리 떨어진 모음만 함정으로 씁니다.
- **철자 단계 순서**: 3글자 → sh·ck 같은 이중글자(한 타일) → 자음군 4글자 → 5글자 한 음절
  (plant, truck) → 두 음절 단어(부모 설정으로 켰을 때만).
- **글자 소리**: 순수한 글자 소리를 내레이터 목소리 하나로 만들어 모든 곳에서 씁니다. 자동 검사가 정확성을
  보장하지는 않으므로 부모님이 귀로 확인할 수 있는 확인 페이지를 함께 만듭니다.
- **음성 속도**: 아이 캐릭터를 위해 빠르게 재생하는 것은 인사·칭찬에만 쓰고, 퀴즈 단어·힌트·글자 소리에는
  쓰지 않습니다(모음 구분이 흐려지기 때문입니다).
- **M1로 앞당김**: 헷갈리는 그림과 이모지 고치기, 첫 문제에 그림 보이기, 한국어 화자가 구분하기 어려운 음을
  함정에서 빼는 임시 규칙, 인사말은 마을 사람마다 처음 한 번만.
- **M2에 추가**: 소리 합치기(blend) 문제, 글자별 정확도, 한국어 도우미 음성(핵심 안내 몇 문장).
  "⭐ 레벨 업!"은 새 최고 단계에 올랐을 때만 띄우고, 모든 마을의 최저 단계는 1입니다.
- **M3 보상 층 줄이기**: 배운 것을 반영하는 보상(단어 스티커, 메달, 자라는 친구)을 중심으로 하고,
  축하 연출은 약 2초 안에 끝나며 누르면 넘어갑니다.
- **M0을 먼저 배포**: 업데이트 알림을 먼저 내보내 다음 배포부터 열린 탭에 알림이 가게 했습니다.
- **저장 형식**: 버전을 표시(`fmt`)하고, 모르는 필드는 지우지 않으며, 옛 방식의 합계도 함께 씁니다.
  서버가 최근 저장본을 보관해 문제가 생기면 되돌릴 수 있게 합니다.
- **녹음**: 처리 방식이 바뀌면 클립 ID도 바뀌게 하고, 이전 배포의 클립은 한 번 더 남겨 두었다가 다음
  배포 때 지웁니다(아직 옛 코드로 열려 있는 탭을 위해서). 모든 문장 변경을 합친 뒤 한 번만 전체 녹음합니다.

## 마일스톤과 배포

마일스톤 하나가 끝날 때마다 main에 배포합니다. 게임을 하고 있는 기기에는 "새로운 버전이 나왔어요!
새로고침" 알림이 뜨고, 시작·로그인 화면에 있으면 저장한 뒤 바로 새로고침합니다(아래 "배포 방식").

### M0: 업데이트 알림 (배포 완료)
- 업데이트 알림과 캐시 무효화, 녹음 검사 도구, 캡틴 로봇 팔·다리 새 디자인(이미 완성되어 함께 배포)

### M1: 아이가 막히는 곳을 없애기 (부모님이 알려주신 문제 중심)
- 오답 피드백(힌트 → 다시 고르기 → 정답 보여주기), 철자 글자별 확인, 악당 반복 해결, 듣기 전에는 카드가 잠김
- 모든 집과 건물에 들어가거나 반응하게 하기(두 판 모두), 문과 동굴 탭 처리, 소품을 누르면 단어 들려주기
- 헷갈리는 그림·이모지 고치기, 첫 문제 그림, 어려운 음 쌍을 함정에서 빼는 임시 규칙, 인사말은 처음 한 번만
- 저장 안전: 업로드 직렬화, 충돌이 나도 새로고침하지 않고 병합, 로그인 시 손님 기록 합치기, 부모 패널 일시정지와 오프라인 처리, 서버 보강, 자동 검사(CI)
- 화면: 긴 단어 맞춤, 가려진 마을 사람 옮기기, 글자가 흐려지지 않는 효과, 대비, 버튼 크기
- 음성: 전부 Generative 엔진으로, 단어는 "Cat." 형태로, 단어 앞 웅얼거림 제거, 순수한 글자 소리, 음량 맞춤, 녹음 자동 검사

### M2: 적응형 난이도와 콘텐츠 확장
- 문제 종류별 단계와 기술 수준 저장(기존 기록에서 이전), 단계가 오르면 "⭐ 레벨 업!"
- 새 단어 은행, 라임, 문장 두 단계, 글자 추가, 한 그림에 한 단어, 다른 이름 사전(별명 겹침 방지)
- 철자 3→4→5글자와 이중글자, 글자 소리 힌트("C says kuh.")
- 부모 패널에 문제 종류별 단계 표시와 ±조정

### M2·M3 배포 전 리뷰에서 고친 것
네 명의 독립 검토자가 M2·M3 변경을 브라우저에서 직접 재현하며 검토해 36건을 찾았고, 다음을 고쳤습니다.
- 멈춤: 옷장 위에서 연 먹이 카드를 닫으면 게임이 멈춰 버리던 문제(심각). 모든 창이 "아직 열려 있는
  창"을 보고 바쁨 상태를 다시 계산하도록 한 곳에 모았습니다. 부모 패널을 앨범 위에서 닫아도 마찬가지.
- 학습: 가장 쉬운 단계의 문장·라임 문제에 한국어 화자가 구분하기 어려운 모음 쌍(pen/pan, hat/jet)이
  나오던 것, 새 그림의 다른 이름(volcano=산, elf=요정, ox=소)이 정답처럼 보이던 것(낚시 게임 포함),
  ll·ss 타일 소리가 녹음되지 않던 것, egg를 /e/ /g/ /g/로 읽던 것, 이중글자 타일에 그 글자가 함정으로
  나오던 것, 이전 기록에서 옮겨 올 때 가장 어려운 단계로 바로 가던 것, 'bow'(두 가지 발음)를 rainbow로,
  캠핑 문장에서 'house'를 엉뚱한 답으로 쓰던 것을 'tub'으로.
- 저장: 부모님이 바꾼 설정·단계가 다른 태블릿의 저장에 덮이던 것(바꾼 시각을 기록해 최신이 이김),
  다른 판(캡틴/공주)에서 손님으로 하다 로그인하면 단계와 설정이 사라지던 것, 놀이 시간이 다른 태블릿
  저장으로 줄어들던 것, 밤새 켜 둔 탭이 다음 날에도 잠든 채로 있던 것, 두 태블릿에서 준 요정 가루가
  하나만 쌓이던 것, 이미 본 스티커가 다시 새것으로 뜨던 것.
- 그 밖: 요정 마을 메달이 기본 설정에서는 영원히 못 받던 것, 낚시 🔁로 놀이 시간 제한을 넘기던 것,
  낚시 코인으로 마을이 열리기 전에 요정·유니콘을 사던 것, 작은 버튼, 캡틴판 앨범 대사.
- 남은 것: 선물 게이지는 두 태블릿에서 동시에 채우면 하나만 남을 수 있음(저장 형식 변경 필요),
  도서관 안에서는 놀이 시간이 지나도 책을 계속 읽을 수 있음. 배포 후 이어서 다룹니다.

### 추가 요청 9가지 (M2·M3 배포 후)
- 바깥을 누르면 닫힘: 스티커북, 오늘의 모험(보물상자), 도서관 책장, 옷장, 상점, 친구 먹이 카드, 미니게임
  끝 카드는 카드 바깥(마을, 위쪽 숫자)을 누르면 👋처럼 닫힙니다. 그 터치로 아이가 걸어가거나 밑의 사람·버튼이
  눌리지 않습니다. 대답해야 하는 질문, 고를 게 남은 선물 카드, 읽는 중인 책, 진행 중인 게임은 그대로 둡니다.
  상자가 열리거나 스티커가 날아가는 중이면 첫 터치는 그 장면만 끝내고, 다음 터치에 닫힙니다.
- 공주판의 남자 캐릭터: 드레스 대신 정장·기사 갑옷·왕자 코트·한복 등 옷 10가지, 기사 투구·왕관·갓 등 모자 9가지,
  칼·방패·활·지팡이 등 손에 드는 것, 기사 망토·용 날개를 남자아이 모습으로 그렸습니다. 선물과 상점에는 지금
  모습에 맞는 것만 나옵니다.
- 마을마다 미니게임: 별빛 숲 "버섯 점프"(라임), 요정 마을 "글자 요정"(철자), 유니콘 마을 "유니콘 달리기"(소리
  합치기), 반짝 동굴 "보물 상자"(읽기). 캡틴판은 공룡알, 드론 배달, 자동차 경주, 크리스탈입니다. 마을 사람에게
  말을 걸면 버튼이 나오고, 아이의 단계에 맞춰(마을 상한까지) 다섯 문제, 끝나면 코인을 줍니다.
- 공주판 동굴 몬스터의 마법: 틀리면 몬스터가 통통 튀며 별·방울·하트·달 마법을 쏘고, 아이 주위의 비눗방울이
  하트로 터뜨립니다(무섭지 않게 짧고 부드럽게). 맞히면 아이의 금빛 별이 날아가 몬스터가 깔깔 웃고 빙글 돌며
  사라집니다.
- 짧던 글자 소리: b·d·g·k·p·t·c는 100~130ms, j·ch·q·w·y는 180~200ms로 길게 다시 잘랐습니다.
- 스티커북 H가 "Hih"로 들리던 것: "Aitch."로 다시 녹음하고, 마지막 /ch/ 뒤에 모음이 붙으면 잘라 내는 처리와
  검사를 넣었습니다. F·S·X도 같은 검사를 받습니다.
- 혼자 읽는 책에서 낱말을 누르면 낱말 전체만 들려줍니다(글자 소리 없이).
- 모을 것 확대: 보물 선반(조개, 보석, 수정 구슬 등 장식품)과 마을마다의 옷·보물을 더해 공주 96개, 왕자 99개,
  로봇 80개입니다. 정답 3개마다 마지막으로 답한 마을 사람이 선물을 주고, 그 사람의 것을 이미 다 가졌으면
  다른 것을 줍니다. 같은 것을 두 번 받지 않습니다.
- 옷장·작업대 탭: 옷, 머리, 손, 등, 머리색, 유니콘, 요정, 보물 선반 등 종류별 탭에 그림으로 보여 주고, 아직 없는
  것은 회색 ❓로 보여 줍니다. 상점도 같은 탭과 그림을 씁니다.

네 명의 검토자(음성, 미니게임·동굴, 옷장·저장, 바깥 터치·통합)가 브라우저에서 직접 재현하며 검토했습니다.

  선반을 따로 한 번 더 저장해 옛 탭이 그대로 남겨 두게 했습니다.
- 미니게임: 철자 게임에서 마지막 글자 직후 🔊를 누르면 멈추던 것, 터치 물결 그리기 오류로 게임 화면이

  버튼이 남아 있던 것, 마지막 물고기를 잡으며 계속 누르던 손가락에 끝 카드가 0.3초 만에 닫히던 것(나온 뒤

- 혼자 읽는 책: 낱말을 누르고 바로 ▶를 누르면 그 낱말이 분홍색으로 남던 것.
- 상점: 다른 탭을 눌러도 앞 탭에서 고른 것이 그대로 사지던 것, 유니콘 마을 뿔·망토가 유니콘 값(12)이던 것(8로).
- 보물을 선반에 둘 때 "옷장에 넣어 둘게요"라고 말하던 것 → 선반 대사를 새로 녹음.
- 음성 파이프라인: 끝까지 잘못 들리는 낱말은 같은 성별의 다른 목소리 녹음을 빌려 쓰고, 포기한 녹음은 다음
  실행에서 한 번 더 시도합니다.

## 배포 방식

- GitHub Pages가 main 브랜치를 그대로 배포합니다. 배포하기 전에 `node tools/stamp.js`를 실행하면
  `index.html`의 모든 스크립트·스타일 주소에 `?v=<빌드 번호>`가 붙고 `version.json`이 바뀝니다.
- `js/update.js`가 3분마다(그리고 화면이 다시 보일 때) `version.json`을 확인합니다.
  새 빌드가 있으면 시작·로그인 화면에서는 바로 새로고침하고, 게임 중이면 알림 배너를 띄워 누르면
  저장한 뒤 새로고침합니다. 다시 받아도 옛 버전이면 무한 반복하지 않도록 막아 두었습니다.
- 첫 배포 전에 이미 열려 있던 탭에는 이 기능이 없으므로 알림이 가지 않습니다. 그 다음 배포부터
  알림이 갑니다.

## 직접 내린 결정 (부모님 부재 중)

- 철자 타일을 누르면 글자 이름 대신 글자 **소리**를 들려줍니다(파닉스 원칙). 마지막에 정답을 말할 때는
  지금처럼 이름으로 철자를 부른 뒤 단어를 말합니다.
- 다시 시도해서 맞히면 별은 주고 선물은 주지 않습니다(계획 검토 반영). 학습 기록과 난이도 판단에는 처음
  맞혔는지만 반영합니다.
- 별 기준(숲 10, 요정 15, 유니콘 25, 동굴 30)은 그대로 둡니다. 요정 마을의 철자는 가장 쉬운 단계부터
  시작하므로 15개도 괜찮습니다.
- 모든 캐릭터를 Generative 음성으로 옮겼습니다. Generative에는 어린이 목소리가 없어서, 아이 캐릭터는
  성인 음성을 조금 빠르게 재생해 어리게 들리도록 했습니다. 퀴즈 단어는 거의 원래 속도로 들립니다.
- 오늘의 모험(퀘스트 3개)은 날짜로 정해져 두 태블릿에서 같고, 다 하면 보물상자에서 코인 5개를 하루
  한 번 줍니다. 하루를 건너뛰어도 아무것도 잃지 않습니다(연속 출석 표시 없음).
- 혼자 읽는 책 8권은 '읽기' 문제 단계에 맞춰 열립니다(첫 권은 항상 열림). 처음 끝까지 읽으면 별 1개,
  다시 읽으면 보상은 없습니다. 쓰는 낱말은 그 단계에서 소리 내어 읽을 수 있는 낱말과 일견 단어 12개뿐이며,
  자동 검사가 이를 지킵니다.
- 낚시 게임은 판마다 코인 3개를 주되, 요정·유니콘 같은 마을 친구는 그 마을 문이 열린 뒤에만 상점에 나옵니다.
